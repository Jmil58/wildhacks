# Desktop Optimizer

Desktop Optimizer is a Windows desktop application designed to help users monitor, clean, and optimize their computer from one easy-to-use interface.

The goal of Desktop Optimizer is to provide useful system information and optimization tools without requiring users to navigate through multiple Windows settings and utilities.

## Features

- **System Monitoring** - View important information about your computer's current performance.
- **Storage Analyzer** - Analyze disk usage to help identify what is taking up storage space.
- **System Cleanup** - Remove unnecessary temporary files to help free up disk space.
- **Performance Tools** - Access tools designed to help improve and maintain system performance.
- **Desktop Interface** - Provides a graphical interface so users do not need to use command-line tools.
- **Windows Executable** - Includes a compiled `.exe` version for users who want to run the application without manually launching the Python source code.

## Inspiration

Desktop Optimizer was created to make computer maintenance simpler and more accessible for users at companies with lower tech knowledge. Windows provides many tools for monitoring and managing a computer, but these tools are often spread across different menus and applications.

Desktop Optimizer brings several of these useful functions together into one application.

## Built With

## How to Run

### Option 1: Windows Executable

1. Download `desktopOptimizer.exe`.
2. Run the executable.
3. Windows may display a security warning because the application is not digitally signed.
4. Follow the application's interface to access the optimization and monitoring tools.

### Option 2: Python Source

The source code is available in:

`desktopOptimizer.py`

Users with the required Python environment and dependencies can run the Python source directly.

## Project Files
